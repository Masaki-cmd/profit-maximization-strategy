# ecommerce-profit-optimization

## プロジェクト概要
このプロジェクトは、Eコマースの売上データ（`ecommerce_sales_data.csv`）を分析し、売上と利益の最大化を目的とした戦略的な提案を行うものです。具体的な課題特定、仮説構築、データ分析、および実現可能な提案とROIの試算を通じて、ビジネスパフォーマンスの向上を目指します。

## データ
- **データソース**: `archive.zip`から抽出された`ecommerce_sales_data.csv`
- **データサイズ**: 3500行、7列
- **主要カラム**: `Order Date`, `Product Name`, `Category`, `Region`, `Quantity`, `Sales`, `Profit`

## 分析フェーズ

### 第一の分析フェーズ (完了)

#### 1. データ準備
- `archive.zip`から`ecommerce_sales_data.csv`を抽出し、Pandas DataFrameとして読み込み。
- 欠損値および重複データがないことを確認。
- `'Order Date'`カラムをdatetime型に変換し、`'Order Year'`, `'Order Month'`, `'Day of Week'`などの時間ベースの特徴量を生成。

#### 2. 課題特定と仮説
- **課題1: 「Office」カテゴリの利益率の低さ**
  - 他のカテゴリ（Accessories, Electronics）と比較して、「Office」カテゴリの利益率がわずかに低い（約16.94% vs 17.33%）。
  - **仮説1**: 「Office」製品の平均販売価格を10%引き上げることで、売上量が2%以上減少することなく、カテゴリ全体の利益が5%増加する。

- **課題2: 高パフォーマンスカテゴリ（Accessories, Electronics）のQ4 YoY成長率の減速**
  - 2023年のQ4 YoY成長率4.17%から2024年には2.87%に減速しており、目標の15%に達していない。
  - **仮説2**: 「Accessories」と「Electronics」に対するQ4の集中的なマーケティングキャンペーンは、これらのカテゴリで前年比15%の売上増加をもたらす。

#### 3. 提案とROI
- **提案1（Officeカテゴリの収益性向上）**
  - SKUレベルでの価格見直し、主要サプライヤーとの交渉、高利益率製品とのクロスセル/アップセルを組み合わせたアプローチ。
  - **ROI試算**: 費用20,000ドルで利益9,269.74ドル増加（5%増）→ **ROI 46.35%**。

- **提案2（Accessories・ElectronicsのQ4売上加速）**
  - ホリデーキャンペーン、ターゲティングされたデジタル広告、ロイヤルティインセンティブを含む集中的なQ4マーケティング戦略。
  - **ROI試算**: 費用50,000ドルで売上125,187ドル増加、利益21,694.91ドル増加→ **ROI 43.39%**。

### 第二の分析フェーズ (進行中)

#### 1. 個別製品のパフォーマンス分析
- 各製品の総売上と総利益を計算し、上位5製品と下位5製品を特定。
- 売上および利益における上位5製品と下位5製品を棒グラフで可視化。

#### 2. 製品の利益率計算
- 各製品の利益率（Profit / Sales * 100）を算出し、特に利益率の低い製品（例: Tablet, Printer）を特定。
- 製品利益率の分布をヒストグラムで可視化し、利益率が最も低い上位5製品を棒グラフで提示。

#### 3. 地域別の製品パフォーマンス分析 (次ステップ)
- 各地域で売上上位3製品を特定し、地域ごとの製品嗜好を理解する。
- ファセット棒グラフまたはヒートマップを用いて、地域別の製品パフォーマンスを可視化する。

#### 4. 新しい利益最大化提案の策定 (次ステップ)
- 個別製品レベル、利益率、地域別の分析に基づいた新しい利益最大化提案を策定する。

#### 5. 最終タスク (次ステップ)
- 新しい分析結果と提案をまとめ、プロジェクトの最終的な知見と提言を提示する。
